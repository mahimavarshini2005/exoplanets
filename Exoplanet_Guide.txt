Lightkurve: Exoplanet Transit Detection Workflow
Import Telescope Data

from lightkurve import search_targetpixelfile
pixelfile = search_targetpixelfile("KIC 8462852", quarter=16).download(quality_bitmask='hardest')

Import telescope images of either telescope ("TESS" or "Kepler").
Looking at location 8462852 (designation of the star).
Quarter defines the time period of the mission on which the image was obtained.
KIC or TESS depending on the telescope you want the data from.

Visualising Target Pixel File

Timeframe of the image:
pixelfile.plot(frame=x)

Animation of the target pixel file over time:
pixelfile.animate


Convert from TargetPixelFile to LightCurve File
Lightkurve files give the brightness of the star over time, helping in identifying periodic changes.
Simple aperture photometry improves the strength of the measured signal relative to the background. Kepler Pipeline aperture is the default option. 

Finding Exoplanet Transit Patterns

We need to check the star's brightness over time to find the periodic pattern.
Identifying the periodic pattern can help identify the existence of a planet crossing the star along with its characteristics.
Use long cadence for finding longer-period variations and exoplanet transits.
Long cadence: measurement every 29.4 mins.
   Short cadence: measurement every 1 min.

Flattening the Light Curve

Flatten command removes the long-term trends that are not useful for exoplanet transit detections. It uses a Savitzky–Golay filter.
